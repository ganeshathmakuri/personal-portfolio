# Personal Portfolio

A simple, responsive portfolio website for **Athmakuri Ganesh**, a full stack developer. It includes a short introduction, skills, social links, and a profile photo.

## Built with

- React
- CSS

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm start
```

The app opens at [http://localhost:3000](http://localhost:3000).

## Available commands

```bash
npm test -- --watchAll=false
npm run build
```

## Personalize

- Replace `public/sample-profile.jpg` with your own photo.
- Update the sample social profile URLs in `src/App.js`.
- Edit your introduction and skills in `src/App.js`.
